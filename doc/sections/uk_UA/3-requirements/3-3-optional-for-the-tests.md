## Необов'язкові пакети для тестів

Якщо необхідно побудувати і виконати доступні тести, встанови GTest разом з GMock або забезпеч доступ до мережі Інтернет, щоб проект зробив їх доступними самостійно (для GNU/Linux):

```
sudo apt install -y libgtest-dev libgmock-dev
```

GMock використовується модульними тестами, які компілюють джерельні коди бібліотеки прямо з дерева проекту разом із замінниками у `src/tests/mocks` і `src/lib/*/tests/mocks`. Компонентні тести натомість лінкуються з реальною динамічною бібліотекою і керують нею лише через публічні заголовкові файли, так само, як це робить проект-споживач.

Тести будуються лише на запит: `ENABLE_UNIT_TESTS=ON` для модульних і `ENABLE_COMPONENT_TESTS=ON` для компонентних. Переглянь підсекції [Вмикання модульного тестування](/doc/sections/uk_UA/5-project-build/testing/5-3-1-enabling-unit-testing.md) і [Вимикання пошуку системного GTest](/doc/sections/uk_UA/5-project-build/testing/5-3-2-disabling-system-GTest-probe.md), а також секцію [Тести проекту](/doc/sections/uk_UA/4-project-structure/4-4-project-tests.md) для детальнішої інформації.
