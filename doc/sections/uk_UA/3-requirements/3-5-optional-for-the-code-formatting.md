## Необов'язкові пакети для форматування коду

Для автоматичного форматування коду бібліотеки за допомогою наявної цілі `clang-format` відповідний інструмент `clang-format` повинен бути встановленим (для GNU/Linux систем):

```
sudo apt install -y clang-format
```

Переглянь деталі конфігурації у підсекції [Вмикання підтримки форматування коду](/doc/sections/uk_UA/5-project-build/code-quality/5-6-enabling-and-performing-code-formatting-target.md).
