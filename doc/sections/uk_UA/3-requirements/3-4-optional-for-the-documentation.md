## Необов'язкові пакети для створення документації

Якщо необхідно генерувати документацію Doxygen з коментарів у джерельних кодах бібліотеки, встанови також систему генерування документації (для GNU/Linux):

```
sudo apt install -y doxygen graphviz
```

Переглянь секцію [Побудова документації](/doc/sections/uk_UA/5-project-build/documentation/5-4-documentation-build.md), як увімкнути підтримку побудови/встановлення документації.
