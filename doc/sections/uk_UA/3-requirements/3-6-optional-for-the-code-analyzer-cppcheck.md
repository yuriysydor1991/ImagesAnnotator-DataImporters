## Необов'язкові пакети для статичного аналізатора коду cppcheck

Для того щоб виконувати статичний аналіз джерельних кодів бібліотеки за допомогою команди `cppcheck`, встанови її наступною командою (для GNU/Linux):

```
sudo apt install -y cppcheck
```

Переглянь підсекцію [Вмикання підтримки цілі статичного аналізатора коду cppcheck](/doc/sections/uk_UA/5-project-build/code-quality/5-7-enabling-the-static-code-analyzer-target-with-cppcheck.md) для детальнішої інформації.
