## Необов'язкові пакети для статичного аналізатора коду clang-tidy

Для того щоб виконувати статичний аналіз джерельних кодів бібліотеки за допомогою команди `clang-tidy`, встанови її наступною командою (для GNU/Linux):

```
sudo apt install -y clang-tidy
```

Переглянь підсекцію [Вмикання підтримки статичного аналізатора коду clang-tidy](/doc/sections/uk_UA/5-project-build/code-quality/5-8-enabling-static-code-analyzer-with-clang-tidy.md), як увімкнути ціль `clang-tidy`.
