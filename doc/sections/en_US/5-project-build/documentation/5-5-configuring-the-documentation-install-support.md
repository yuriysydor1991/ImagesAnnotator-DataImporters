## Configuring the documentation install support

The generated Doxygen documentation can be installed together with the library
by setting both the `ENABLE_DOC_DOXYGEN` and the `DOXYGEN_DO_INSTALL` variables
to `ON` during the configure stage.

```
# inside the project root directory

cmake -S . -B build \
  -DCMAKE_PREFIX_PATH=/path/to/data-drivers-install-prefix \
  -DENABLE_DOC_DOXYGEN=ON \
  -DDOXYGEN_DO_INSTALL=ON
```

The documentation is not generated by the default build, so build the
`Doxygen-doc` target before installing - otherwise the install step has no
directory to copy:

```
# inside the project root directory

cmake --build build -j$(nproc)
cmake --build build --target Doxygen-doc
cmake --install build --prefix /usr/local
```

The HTML tree lands in `<prefix>/share/docs/<DOXYGEN_OUT_HTML_NAME>`, by
default `<prefix>/share/docs/ImagesAnnotatorDataImporters-0.14-html`. It is
installed under the `Documentation` install component, so a packager may pick
it up separately from the `Runtime` and `Development` components of the
library itself.

The `DOXYGEN_OUT_HTML_NAME` CMake variable sets the documentation HTML
directory name (it is passed into the generated `Doxyfile` as well), and
`DOXYGEN_OUTPUT_DIR` sets the directory the tree is generated into before the
install copies it.
