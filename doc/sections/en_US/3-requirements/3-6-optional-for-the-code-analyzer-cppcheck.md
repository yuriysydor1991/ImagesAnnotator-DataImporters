## Optional for the code analyzer (cppcheck)

In order to perform a static code analysis of the library sources with the `cppcheck` command install it with next command (GNU/Linux based):

```
sudo apt install -y cppcheck
```

Examine the [Enabling the static code analyzer target with cppcheck](/doc/sections/en_US/5-project-build/code-quality/5-7-enabling-the-static-code-analyzer-target-with-cppcheck.md) subsection for more details.
